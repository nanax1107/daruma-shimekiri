だるまさんが締め切った

3D版・上から視点（試作）

締め切り前夜の大学。欲しい牌の上に立って待とう。ダルマが振り向いた瞬間、足元の牌がツモになる。麻雀の役を作ってダルマを倒そう。 振り向いている間に動くと見つかって、後ろから締め切りの壁が迫ってくる。

← ↑ → ↓1マスずつ移動（押しっぱなしで連続移動）。振り向き中は動かない！
牌の上で待つダルマが振り向いた瞬間、足元の牌をツモ（捨て忘れはツモ切り）
手牌をクリックその牌を捨てる（右端が今ツモった牌）
Space上がり → ダルマに攻撃（翻数＝ダメージ）。上がると壁が後退
右下のボタン「もういいや」＝手牌を配り直す（回数制限あり・壁が迫る）
「視点」ボタンで上から／低め／全体を切り替え

役：ツモ1／タンヤオ1／七対子2／対々和2／清一色6。ドラ1枚につき＋1翻。上がりの形は4面子1雀頭か七対子。字牌はなし。
