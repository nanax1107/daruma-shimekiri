だるまさんが締め切った

試作版

締め切り前夜の大学。欲しい牌の上に立って待とう。ダルマが振り向いた瞬間、足元の牌がツモになる。麻雀の役を作って倒そう。 振り向いている間に動くと見つかって、後ろから締め切りの壁が迫ってくる。

操作

WASD移動（振り向き中は止まる！）
マウス / ← →視点移動（マウスが使えない時は ← → キーかドラッグ）
牌の上で待つダルマが振り向いた時に足元の牌をツモ（捨て忘れはツモ切り）
E / 右クリック長押しズーム（奥の牌を確認）
ホイール / Z・X捨てる牌を選ぶ
左クリック / F選んだ牌を捨てる（牌を直接クリックでも可）
Space上がり → ダルマに攻撃（翻数＝ダメージ）
Qもういいや：手牌を配り直す（回数制限あり・壁が迫る）

役：ツモ1／タンヤオ1／七対子2／対々和2／清一色6。ドラ1枚につき＋1翻。上がりの形は4面子1雀頭か七対子。字牌はなし。
上がると締め切りの壁が後退する。
